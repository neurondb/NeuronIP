## Overview

NeuronIP provides onboarding flows for new users (e.g. feature discovery, first-time setup) and a partner ecosystem for sales enablement and third-party integrations. Onboarding improves time-to-value; the partner ecosystem supports go-to-market and extensibility.

---

## Key Capabilities

- **Onboarding** – First-time user experience, feature discovery, setup wizards
- **Partners** – Partner program, sales enablement, partner-specific APIs or content
- **Feature discovery** – In-app guidance for key features (see frontend onboarding components)
