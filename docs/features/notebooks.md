## Overview

NeuronIP supports notebooks for interactive analysis, documentation, and collaboration. Notebooks are backed by the ML/notebooks service and persistence (migration 061), allowing users to create, edit, and run notebook-style content within the platform.

---

## Key Capabilities

- **Notebook CRUD** – Create, read, update, delete notebooks
- **Execution** – Run cells and persist results
- **Collaboration** – Share and collaborate on notebooks (see collaboration features)
